# Вездеход - сайт-визитка

Одностраничный статический сайт с контактами компании.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в GitHub-репозиторий.
2. В настройках репозитория откройте **Pages**.
3. Выберите публикацию из ветки `main`, папка `/root`.
4. Сохраните настройки.

## Файлы

- `index.html` - главная страница.
- `styles.css` - оформление и адаптивность.
- `script.js` - резервное отображение названия, если логотип не загрузился.
- `assets/Вездеход_лого.jpg` - логотип компании.
- `assets/КАРТОЧКА  ПРЕДПРИЯТИЯ ИнфоТехКапитал.docx` - карточка компании для скачивания.

Если последние два файла не лежат в папке `assets`, добавьте их туда с такими же именами.
